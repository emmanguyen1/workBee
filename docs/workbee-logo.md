# workBee professional bee

Final asset: `hives/careers/static/workbee-logo.png`, used in the website header
and favicon. Generated with the built-in image-generation tool as an edit of the
scientist-bee draft. The final logo wears a navy blazer and carries a work device.
Its transparent alpha channel is preserved. No external API key was used.

## Final prompt

Use case: logo-brand; edit the attached workBee bee mascot. Preserve the friendly
bee's face, yellow and navy identity, clean thick outlines, wings, antennae,
centered square silhouette and transparent background. Replace the scientist
styling entirely: remove lab goggles, white lab coat, flask, and all laboratory
elements. Dress the bee in a well-fitted navy blazer over a neat white shirt,
professional but warm and approachable. Give the bee a small closed laptop or
smart work portfolio held naturally in one hand to represent productive
professional work. No tie necessary. Make it an elegant working professional
bee suitable for an internship and careers website. Navy #0E1D35 / #2B3D5B,
honey yellow, white, light grey. Compact mark readable at 48–64 pixels; avoid
tiny details. No text, no lettering, no watermark, no scene, no background shadow.
Actual transparent background.

## Employer branding

`hives/careers/static/logos/` contains 59 cached PNG favicon images retrieved
through Google's favicon service using known official employer domains.
Only configured domain filenames are served. Unmapped employers use initials;
missing cached images can fall back to the known-domain favicon service.


## Assistant variant

`workbee-assistant.png` is a generated transparent sibling of the original mark,
with one hand waving and the other holding the same tablet. The navy blazer,
white shirt, face, wings and drawing style are preserved. It is used only in the
bottom-right help launcher; the former hero mascot callout was removed.
